# MY RUNNER 3D

Endless runner original para navegador, con controles de teclado y táctiles, tres carriles, obstáculos, monedas, puntuación y personalización visual del corredor mediante fotografías.

> Estado inicial: prototipo jugable en desarrollo. La generación de modelos 3D mediante IA requiere configurar un proveedor externo y sus credenciales en el backend; nunca se exponen claves en el navegador.
